## 2. Technical approach

### Compatibility
- `compat.py`: `BlockGroup` (or `None`), `telepath_register`, `JSContext`, `HAS_FORM_LAYOUT`.
- Migrations: edit the dependency of `prblm_builder_blocks.0001` (safe: Django only checks that
  the dependency exists, so sites that already applied it are unaffected) and the test apps'.
- `tests/test_compat.py`: migration dependency guard; the mixin is a no-op without
  `BlockGroup`.

### Overlap (`frames.js`, `builder.js`, `previews.py`)
- `measure()` also returns `over` (px the section's real box extends above the frame's top —
  negative top margin / negative `top`), `under` (px below its end), and for chrome
  `overlay`: the header's outermost visible element is `position: fixed|absolute` and has a
  transparent background (itself and its wrappers up to `<body>`).
- Overlap on: the frame gets `padding-top: over` / `padding-bottom: under` on `<body>` (so
  nothing is drawn above 0), a transparent `html, body` background, and its host is pulled up
  by `over × scale` with a higher `z-index`, so it covers the end of the previous section as
  on the live page. Overlay header: its host is absolutely positioned over the top of the
  first section, transparent, above it. Pointer events: overlapping hosts pass clicks through
  outside the section's own box (selection by the section's box, not the frame).
- Overlap off: a style in the frame cancels negative margins on the section's top-level
  elements; the header is stacked as before.
- Setting reader `canvas_overlap()`; per-site `canvas_overlap` via `sites.config`; passed to the
  canvas as `data-canvas-overlap`.

### Demo content (`demo.py`)
- `_repair_pattern(block, value)`: on a `RegexBlock`/validator failure, try the candidate list.
- `_score(block, prep)`: (filled fields, has image, length).

### Library and sidebar (`registry.py`, `views.py`, `demo.html`, `builder.html`)
- `registry.sort_by_usage(groups, counts)`; counts from `demo.usage` (site-scoped).
- `sites.choices()`: `[]` unless 2+ Sites; template renders tabs (≤5) or a select.
- Card header CSS.
- `_library_sources()` for `"all"`: Page subclasses only.

### Docs
README (versions, settings rows, overlap, order, refresh, uninstalling, admin additions),
PREVIEWS.md (overlap, analytics), CHANGELOG 0.9.0, history doc, CLAUDE.md.

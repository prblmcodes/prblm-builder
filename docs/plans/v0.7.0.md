## 1. Decisions (agreed)

| # | Topic | Decision |
|---|---|---|
| 1 | **Release** | Everything below ships together as **0.7.0** (no 0.6.1). |
| 2 | **Demo content chain** | Per **field**, in order: `preview_value` (partial allowed) → **real content of the same block** → the block's own defaults → **neutral labelled text**. No editor-defined demo content (maybe later). |
| 3 | **Borrowing real content** | Only from the **same block (class)**, only sections on **live, published** pages, only sections an editor **changed** (never "Not edited yet" demo sections), and only values that pass the block's `clean()`. Never borrow fields from other blocks. Optional fields the real section left empty get generated content. |
| 4 | **Generated text** | Neutral and obviously placeholder, built from the field's label / help text ("Section heading", "Short description of this section…"). The **amount fits the field**: heading-like → a few words; `CharBlock` → a short line within `max_length`; `TextBlock` → 1–2 sentences; `RichTextBlock` → a short paragraph (body-like names: two paragraphs). No repeats inside one section. |
| 5 | **Images** | (1) a real image from the same field of the same block; (2) a library image that **fits the role and shape** — wide raster photos for banners / heroes / backgrounds (never SVG or transparent PNG), square / SVG / transparent for logos / icons / avatars; (3) a **role-shaped labelled placeholder image** created once in a **"Builder placeholders"** collection (wide "Banner", square "Logo / icon", "Photo"). Rendered via a rendition, never the original. No demo-collection setting. `PRBLM_BUILDER_PLACEHOLDER_IMAGES = False` still turns creation off. |
| 6 | **Other fallbacks** | Documents: a document used in the same field elsewhere, else empty if optional. Links: one consistent pair (type + its value), preferring a real internal page, else `#`. Never `example.com` or a random unrelated file. Lists: `default` → `min_num` → 3, capped at `max_num`, items varied. |
| 7 | **Per-site previews** | Today's global settings stay as the default. New optional **`PRBLM_BUILDER_PREVIEW_SITES`** keyed by Wagtail Site hostname: `css`, `js`, `body_class`, `header_template`, `footer_template`, `template`. Chosen by the page's Site; the Block library gets a site switcher. |
| 8 | **Preview template** | Optional **`PRBLM_BUILDER_PREVIEW_TEMPLATE`** (also per site): a developer-written template extending the site's `base.html`; the section is inserted as `{{ prblm_section }}`. Developer-only, nothing for editors. Plus **dict entries** in `_CSS` / `_JS` for script / link options. |
| 9 | **`vh` heights** | **`PRBLM_BUILDER_CANVAS_HEIGHT`** (default 900): frames keep a viewport at least that tall, so `70vh` = 630px as on a typical screen. |
| 10 | **Fixed headers on Builder pages** | Measured automatically (small JS); overridable with CSS variable `--prblm-header-offset`. |
| 11 | **Unused blocks** | Block library **filter** (All / Used on pages / Not used yet) and **"Used on N pages"** per block, linking to them. No badge, no hiding setting, no source label. |
| 12 | **⚙ panel** | Number inputs with min/max; values **checked as you type** with the block's own rules; no empty "—" option when a dropdown has a default. |
| 13 | **Placeholder title** | Publishing a page still titled "Untitled page N" shows a **warning** (publishing still allowed). |
| 14 | **Two-column forms** | One column below **720px** of form width (was 560px). |

## 2. Bugs (A)

### A1. Partial `preview_value`
`explicit_preview_value()` returns a *partial* value. A new `demo.build(block, name)` merges it
field by field with the rest of the chain (§3), then validates. A `preview_value` that still
can't produce a valid value puts the block under **"Couldn't preview"** with the field name.
**Test:** `preview_value` without a required image → new section saves.

### A2. Never borrow the plugin's own demo content
- The real-content index (`_build_instance_index`) only reads **live, published** pages
  (`live=True`, the published revision's content, not drafts).
- **Seeded-section log:** a small core model `SeededSection(page, section_id, value_hash)`
  written when `layout.reconcile` seeds a new section. A section whose current value still
  has its seeded hash is demo content: skipped by the index, and shown "Not edited yet"
  (more reliable than today's comparison, which breaks when the generator changes).
  Sections seeded before 0.7 aren't in the log → today's comparison as a fallback.
- Every borrowed value passes `block.clean()`; a failing one is skipped (next best instance).
- **Tests:** a published unedited demo section isn't borrowed; a draft-only one isn't; an
  invalid one isn't; an edited published one is.

### A3. Dropping a section in its own place isn't a change
`builder.js` `onEnd`: compare `structureSig(collect())` before/after; no dirty, refresh or
history entry if unchanged. `onAdd` stays a change.

### A4. Fixed / sticky headers
- **(a) Canvas:** `chromeHeight()` also measures fixed / sticky children that are visible and
  at the top of the frame; still skips hidden (`display:none`, `visibility:hidden`, zero
  size) and off-screen ones (closed mobile menus).
- **(b) Live Builder page:** `builder_page.html` wraps the sections in
  `<main style="padding-top:var(--prblm-header-offset,0)">`; a few lines of JS set the
  variable to the header's height when it's fixed or sticky (and on resize). A developer
  can set `--prblm-header-offset` in CSS instead.

### A5. `vh` heights
Each section frame keeps a viewport of at least `PRBLM_BUILDER_CANVAS_HEIGHT` px: the iframe
is that tall while measuring; the host clips to the content height. Content taller than that
gets a taller frame (an `h-screen` section then equals its frame — stable, no loop). Same for
thumbnails and the Block library.

### A6. Empty header / footer
A chrome frame with no visible content (no text, no media) is hidden. A
`prblm_builder_chrome_for_page` hook returning `""` means "no header" (vs `None`, "not mine")
— checked server-side so the frame isn't even loaded.

### A7. Sections cut off (defensive)
Measure `max(body.scrollHeight, documentElement.scrollHeight, bottom of the last in-flow
child + its margin-bottom)`; observe `documentElement` too; re-fit on image `load` inside the
frame and on `document.fonts.ready`; a throttled frame-local MutationObserver; re-fit
after device-size changes until stable (not once at 240ms).

### A8. Auto-save rejected (`invalid_revision`)
Try to reproduce (two editor tabs, fast reloads). Whatever the cause, when auto-save fails
after a Layout change, the banner says clearly: "Couldn't save automatically — click **Save
draft** to keep your layout."

## 3. Demo content (C) — `prblm_builder/demo.py` (new, replaces the synth part of `previews.py`)

One function builds a value **per field**, recursing into Struct / List / Stream blocks:

1. `preview_value` for that field, if given.
2. The best **real** value of the same block (decision 3), field by field: a field the real
   section left empty falls through to the next steps.
3. The field's own `default` (incl. `ChoiceBlock` defaults).
4. Generated:
   - **Text** (decision 4): `label` / `help_text` / name → "Section heading", "Button label",
     "Short description of this section"; length by type and `max_length`; numbered when a
     list repeats it ("Feature 1", "Feature 2").
   - **Links:** detect link-like StructBlocks generically — a `ChoiceBlock` whose choices
     match sibling field names (`page`, `url`, `custom_url`, `email`, `anchor`, `document`,
     `file`, `phone`). Set the type and **only** its field: a real live page if any, else
     anchor `#`. Covers the built-in LinkBlock and `wagtail-link-block`.
   - **Images** (decision 5): role from field name / label / help text (`background`,
     `hero`, `banner`, `cover` → wide; `logo`, `icon`, `avatar`, `badge` → square / vector;
     else photo). Shape from width/height ratio, file type (SVG), transparency (PNG mode).
     Placeholder images per role in the "Builder placeholders" collection.
   - **Documents:** used in the same field elsewhere, else empty when optional, else a small
     "Example document" text file in the placeholders collection.
   - **Choosers for snippets / pages:** a live page / the first snippet.
   - **Lists** (decision 6).
5. `block.clean()` on the whole value; a field that fails falls back **one step** for that
   field only (0.6's repair, generalised).

The Block library and thumbnails trim long text as today (`&trim=1`); the canvas never trims.

## 4. Previews (B)

### B1. Per-site assets — `PRBLM_BUILDER_PREVIEW_SITES`
```python
PRBLM_BUILDER_PREVIEW_SITES = {
    "shop.example.com": {"css": ["shop/css/main.css"], "js": ["shop/js/app.js"],
                         "body_class": "font-shop", "header_template": "shop/header.html"},
}
```
- Resolved from the page's Site (`page.get_site()`), else the request's Site; missing keys
  fall back to the global settings.
- Used by canvas frames, chrome frames, thumbnails, Builder pages (`prblm_site_css` etc.).
- Block library: a site switcher (`?site=<hostname>`), default = the request's Site.
- README: document the `prblm_builder_chrome_for_page` hook with an example.

### B2. `PRBLM_BUILDER_PREVIEW_TEMPLATE`
```django
{# templates/prblm_preview.html #}
{% extends "base.html" %}
{% block header %}{% endblock %}{% block footer %}{% endblock %}
{% block content %}{{ prblm_section }}{% endblock %}
```
- When set (globally or per site), `previews.frame()` renders it with the usual context
  (`request`, `page` when known) + `prblm_section`. `loading="lazy"` is still stripped; the
  plugin adds only its tiny measuring hook.
- Canvas sizing measures the section element (wrapped in `<div data-prblm-section>`), not the
  whole template, so wrappers / padding in `base.html` don't inflate the height.
- Chrome frames use it too (header/footer blocks emptied by the template itself).

### B3. Dict entries for assets
`PRBLM_BUILDER_PREVIEW_JS` / `_CSS` (and per-site lists) accept strings as today or dicts:
`{"src": "js/app.js", "defer": True, "type": "module", "integrity": "…", "crossorigin": "anonymous"}`,
`{"inline": "window.X = 1"}`, `{"href": "css/print.css", "media": "print"}`.
Docs: list order = load order; libraries first; Alpine plugins before Alpine core.
